# Demos repository

Each top-level folder is a self-contained demo with its own `AGENTS.md`:

- `datacloud-analytics-demo/` — workforce analytics (pandas metrics engine + React dashboard). Jira tickets for it live in
  project MDD on cog-gtm.atlassian.net (label `datacloud-analytics-demo`). Follow `datacloud-analytics-demo/PLAYBOOK.md`.
- `datacloud-migration-demo/` — legacy EMR migration demo.

Work inside the relevant folder; open PRs against `main` (never push to `main` directly from a ticket).
